## The entry

A single-line joke about office life, written as one sentence:

> Our office plant has survived three rounds of layoffs, two CEOs, and a merger — HR just gave it a promotion and my desk.

The setup is a detail anyone who has worked in an office recognises — the
indestructible office plant that outlives every reorganisation. The punchline
flips the usual layoff story: instead of the plant being thrown out with the
furniture, it is the one that gets promoted, and it takes the narrator's desk.
One line, 120 characters, no emoji.

## How it works

`main.py` (Python 3, standard library only) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The output is fully
deterministic: the same fixed string is written on every run, with no
trailing newline, so the file is exactly the joke text and nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
